# 🐝 WriteBee

WriteBee is an interactive educational web application designed to help children improve their early writing skills through guided tracing exercises.

The app provides structured levels for practicing lines and basic shapes in a fun and child-friendly environment. With responsive design and a clean UI, WriteBee aims to create a comfortable and engaging learning experience.

## ✨ Features
- Line and shape tracing exercises
- Multiple levels with progressive difficulty
- Interactive canvas-based tracing
- Dynamic stroke color selection
- Responsive layout (mobile-friendly)
- Reward modal for positive reinforcement

## 🛠 Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5

## 🎯 Goal
WriteBee is built to combine learning and fun, helping children develop motor skills and writing confidence in a playful digital environment.
