Palette icon:
- pallate.png (floating palette icon PNG, recommended 128x128, transparent background)
- pallate.svg (vector fallback)

To use your provided palette image named `pallate.png`:
1. Save the PNG to this folder as `pallate.png` (transparent background, 128x128 recommended).
2. The app will use `assets/images/pallate.png` automatically for the floating palette icon. If `pallate.png` is not present, `pallate.svg` will be used as a fallback.

You uploaded an image during the conversation — to use it as the palette icon (permanently):
1. Download the image from the chat/attachment and save it to this folder as `pallate.png`.
2. Run the dev server and refresh the page to see it in place.

Tip: add `?admin=1` to the site URL to show the temporary uploader overlay if you want to test images in-session.
